# AGENTS.md

## Project context
This is a business scheduling/calendar dashboard for internal work use.

## Design direction
Use Impeccable as the UI quality standard.
The interface must feel clean, professional, calm, and business-ready.

## Brand
- Green corporate/insurance-inspired branding
- Clear hierarchy
- High readability
- Responsive dashboard layout

## Avoid
- Purple gradients
- Generic SaaS look
- Too many nested cards
- Low contrast gray text
- Flashy animation
- Changing logic just to improve visuals

## Rules
- Do not delete files unless explicitly asked.
- Do not change database schema.
- Do not change auth, routing, or API contracts unless explicitly asked.
- Before editing, inspect related files and explain the plan.
- After editing, summarize changed files and how to test.
